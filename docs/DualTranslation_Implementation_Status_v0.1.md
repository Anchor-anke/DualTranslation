## 已验证项目

- 前端：Prettier、ESLint、TypeScript 严格检查、生产构建。
- 自动化：10 个前端/Schema 测试；Rust 单元、Repository 和回环 Mock Server 测试。
- 模型 Mock：成功响应、Markdown JSON、401/403、404、429、500、连接失败、超时、畸形响应、一次修复成功与修复后仍失败。
- 隐私：不主动读取剪贴板、敏感请求发送前阻断、原文二次确认、显式敏感历史授权、API Key 不进入 SQLite 表结构。
- 本地视觉：1280 宽和 720 最小宽度无横向溢出，设置页响应式布局正常，浏览器控制台无错误或警告。
- 桌面构建：macOS debug 无 bundle 构建成功，产物位于 `src-tauri/target/debug/dual-translation`。
